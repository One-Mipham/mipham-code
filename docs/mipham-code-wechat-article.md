## 别人在讲「一切皆插件」，我们在造一颗会自我进化的「金刚心」

> 最近后台常收到一个问题：DeepSeek 的 Harness 这么火，你们慌不慌？

先说答案：**不慌，反而更笃定了。** 因为这场讨论，恰好帮我们把一件想说很久的事，讲清楚了。

---

### 一、「一切皆插件」，我们也是这么干的

「一切皆插件」这四个字，道破了下一代 Agent 框架的真相：**能力不该写死在核心里，而该像插件一样可插拔。**

这一点，Mipham Code 从内核层就开始践行。我们自建了一颗内核，名字叫 **Vajra-Hṛdaya——金刚心**。

金刚心只有四个原语：**Context、Effect、派发、Service 状态机**。新增任何能力，都不改内核，而是「挂载」上去。这才是「一切皆插件」真正落地的样子——**不是把东西堆成插件，而是内核生来就为插件而设计。**

### 二、但插件不是终局

如果故事停在「一切皆插件」，那 Mipham Code 就只是一个更灵活的工具。

我们想问一个更尖锐的问题：

> **当所有能力都能被插上之后，是谁在让这个系统，自己变得更好？**

这，才是我们和所有「Coding Agent」真正的分水岭。

### 三、我们的答案，叫 CRSI

**CRSI——Continuous Recursive Self-Improvement，永不停息的递归自改进。**

这是华安麦逄对「递归自改进」这一 AI 终极命题的命名。它不是 PPT 里的愿景，而是已经工程化落地的三套子系统：

1. **会学习** 🧠 —— PatternAnalyzer 分析行为模式，AutoMemoryEngine 沉淀记忆，ExperienceRuleEngine 生成经验规则，EffectivenessTracker 追踪每条规则的真实效果；
2. **会免疫** 🛡️ —— ErrorSignatureDB 记住每一次错误的「签名」，PreFlightChecker 在下次出手前先拦截；
3. **会安全地改自己** 🔒 —— CrsiSandbox 五阶段受控自修改，让「自我进化」永远在安全笼子里进行。

换句话说：**「一切皆插件」决定了它有多大，CRSI 决定了它有多强。**

### 四、它不止会写代码

一个 Coding Agent，帮你把代码写对。

Mipham Code，是一个完整的智能体平台：

- **Agents**：一个终端，调度一个后台 Agent 团队；
- **Hooks**：13 种生命周期钩子，你在任何一环都能安全介入；
- **Skills**：23 项内置技能，双轨运行时，可无限扩展；
- **多模型**：不绑定任何一家——Claude、GPT、DeepSeek、通义、豆包、混元、MiphamAI 自有模型，统一接入。

**它不忠于某一个模型，只忠于「变得更好」这件事本身。**

### 五、开放，是我们的护城河

Mipham Code 是 **Apache 2.0 开源**的。有人问：核心技术都开源了，护城河在哪？

我们的答案是：**当你把「永不停息的自我改进」做成产品本身，别人抄走的只是代码，抄不走一颗会进化的内核。**
